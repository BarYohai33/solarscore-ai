# SolarScore AI

An explainable lead qualification and scoring
application for the photovoltaic industry.

## Project Overview

SolarScore AI helps businesses evaluate solar
installation appointments using configurable rules.
The application provides a French-language user interface,
appointment assessments, and detailed scoring explanations.

## Planned Features

- Appointment eligibility validation
- Lead scoring from 0 to 100
- Financial feasibility indicators
- Detailed explanations for each score
- Appointment history
- AI-powered analysis and automation

## Planned Tech Stack

- Python
- FastAPI
- PostgreSQL
- React
- n8n
- Docker
